# JE_Spice
JE_Spice is a personal project that I designed and implemented in C++.
It is a circuit analysis tool inspired by the well-known SPICE program, created as a way to practice and learn about electronic circuit simulation and numerical methods.

Project Name: JE_Spice

Category: Circuit Analysis / Simulation

Language: C++

Start Date: 1403/12/30 (Solar Calendar)

Author: Student Project of OOP

The project aims to provide a simple environment for analyzing circuits and experimenting with simulation ideas. It’s not a professional tool, but rather a step in learning and exploring how such systems work.
